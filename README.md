# Personal Information Website

## Project Description
This project is a simple personal information website created using HTML and CSS.  
It displays basic details about me such as my background, hobbies, education, and goals.
The design is simple, clean, and easy to navigate.

This project was made as part of a school requirement to practice basic web development.

## Features
- Two-page website (About Me and More About Me)
- Simple and clean design
- Responsive layout using CSS Flexbox
- Styled sections and lists without emojis or external libraries
- Easy navigation between pages

## Technologies Used
- HTML5
- CSS3

## File Structure
project-folder/

## How to Run the Project
1. Download or clone the project files.
2. Make sure all files are in the same folder.
3. Open `index.html` using any web browser.
4. Use the links or buttons to navigate through the pages.

## Purpose of the Project
The purpose of this project is to practice:
- Creating web pages using HTML
- Styling layouts using CSS
- Organizing content in a simple website
- Building a personal information webpage
